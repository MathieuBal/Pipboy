# Brouillard de guerre

Dans **Table de jeu**, sélectionnez une scène, puis **Brouillard de guerre**.

1. **Masquer toute la carte** couvre ses 64 zones. En préparation privée, cela ne change pas la scène actuellement affichée.
2. **Dévoiler des zones** : touchez les cases explorées. Le **Pinceau large** agit sur un carré de 3 × 3 cases. Zoomez pour viser plus précisément sur téléphone.
3. **Remasquer des zones** permet de recouvrir des cases. **Annuler le dernier tracé** annule la dernière modification de la scène ; ce retour disparaît en quittant la table ou après rechargement.
4. **Afficher cette scène** la partage avec son brouillard. Les changements suivants se synchronisent avec les joueurs.

Le MJ voit la carte sous des hachures ; les joueurs voient des cases opaques. Les pions dont le centre est dans une case couverte ne s’affichent pas côté joueur. Les pions secrets restent secrets même après dévoilement du terrain.

Le brouillard est enregistré par scène et inclus dans les sauvegardes complètes de campagne. Aucun changement de configuration Supabase n’est nécessaire. Il utilise le transport existant des éléments de carte.

Il s’agit d’un masque d’exploration visuel, pas d’un contrôle d’accès au fichier image de la carte. Gardez les secrets du scénario dans les fiches MJ non révélées.
